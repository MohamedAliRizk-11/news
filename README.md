# 📰 News App

A Flutter-based News Application that allows users to explore the latest news across different categories and read full articles through an integrated web view.

This project was built as a practical learning experience to improve my Flutter development skills, strengthen my UI development abilities, and gain hands-on experience with REST API integration.

## ✨ Features

- Browse the latest news articles.
- Explore news by different categories.
- View articles with their images, titles, and descriptions.
- Open and read full articles using an in-app WebView.
- Navigate between the home screen and category screens.
- Dynamic content fetched from a News API.

## 🛠️ Technologies & Tools

- **Dart** – Programming language.
- **Flutter** – Cross-platform application development.
- **REST API** – Fetching and handling external news data.
- **HTTP** – Making API requests.
- **WebView** – Displaying full news articles inside the app.
- **Material Design** – Building the user interface.

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/MohamedAliRizk-11/news.git
```

2. Navigate to the project directory:

```bash
cd news
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
